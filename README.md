# CodexCreatedWebsite

This repository contains a small mock website for managing film creation assets.

## Usage

Open `src/index.html` in any modern web browser. The page displays the film
production workflow with eleven steps. Each step has sections for Input Assets
and Output Assets. Use the forms to add asset names. When an output asset is
added for a step, it automatically becomes an input asset for the next step to
help track the asset lifecycle.
